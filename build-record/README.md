# Build record

The evidence of how the semaphores and the screens were made: every build, the superseded and the refuted ones included,
with the tools and the notes of the time. It is a record, not the place to take files from. The files to use, to print
and to cite are in [`../semaphores/`](../semaphores/).

- **Kept as it was built.** Paths, folder names and file names are the working names of the time ("proposals",
  "medallion", "coin", "owl"), so that every reference inside the configs, READMEs and scripts here resolves.
- **The final build** is in `master/states/proposals/notation/final-masters-2026-10-05/`, with that build's own README
  and its `MANIFEST.json` of hashes. The folder is named "proposals". Its four masters and forty pictures are the same
  files as those in `../semaphores/`, byte for byte.
- **The scripts are records, not instructions.** Some read files that are not in the release; `../RELEASE-MANIFEST.md`
  says which, and why.
- **This folder was named `artwork/`** in releases 1.0.0 and 1.1.0. Nothing inside it changed with the name.
