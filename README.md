# The Tetrasemaphore

**Four sign-bearers. One law: every mark must survive the operation it names.**

The Tetrasemaphore is a finite algebra of epistemic states rendered as
four self-identifying glyphs — the Klein four-group (V₄ ≅ D₂) carried
in visual form:

| State | Element | Operation | Fixed set (gold) |
|---|---|---|---|
| NORMATIVE | `I` | identity | every point |
| NON-NORMATIVE | `σᵥ` | vertical reflection | the vertical axis |
| CRITICAL | `C₂` | half-turn | the centre point |
| METACOGNITIVE | `σₕ` | horizontal reflection | the horizontal axis |

with `σᵥ∘σᵥ = σₕ∘σₕ = C₂∘C₂ = I` and the composition of any two
non-identity elements yielding the third.

## The design law

1. **Self-identification** — each glyph is invariant under exactly its
   own operation (stabiliser = the subgroup it names). Fold it; only its
   own fold returns it.
2. **Notation is the signal** — the mathematical marks (`I`, `σᵥ`, `C₂`,
   `σₕ`) are typeset exactly as they appear in mathematical text, and are
   never redrawn, stylised, or "improved." Decoration lives in the frame,
   never in the letterform.
3. **Tokens need mirrors** — a notation token placed off the glyph's own
   axis must appear with its image under the operation, or the glyph's
   caption is false. Even the name must obey the law it names.
4. **Gold marks the fixed points** — gold appears exactly on what the
   operation leaves in place, and nowhere else.

## Lineage

The Tetrasemaphore generalises the
[Owl Semaphore](https://github.com/IT-Help-San-Diego/owl-semaphore)
(CC-BY-4.0), whose owl — Athena's, Western, culturally licensed — was the
first carrier. The four notational glyphs are the carrier that needs no
culture: the signal is universal, owned by no one, checkable by anyone.

Publication artifacts are rendered by
[owl-semaphore-press](https://github.com/IT-Help-San-Diego/owl-semaphore-press),
the shared integrity-regime toolchain (Typst pipeline, provenance
stamping, Zenodo DOI automation).

Framework home: **tetrasemaphore.systems**
