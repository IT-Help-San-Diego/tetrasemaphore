# Changelog

## [1.0.0] — 2026-10-22

First public release of the Tetrasemaphore (`https://tetrasemaphore.systems/`, version DOI `10.5281/zenodo.23575816`, concept DOI `10.5281/zenodo.23575814`). Continues the Owl Semaphore Badge System (concept DOI `10.5281/zenodo.19473697`, `v3.0.1` DOI `10.5281/zenodo.21524422`), which stays published and citable under its own name.

- **Public note & methods note (`README.md`, `methods/`, `pdf/`):** Public note (`README.md`), methods note 01 (`methods/tetrasemaphore-methods-note-01.md` and revision 1 `methods/tetrasemaphore-methods-note-01-rev1.md`), and their PDF/A-2a typeset copies (`pdf/TETRASEMAPHORE-PUBLIC-NOTE.pdf` and `pdf/TETRASEMAPHORE-METHODS-NOTE-01.pdf`), built by `tools/generate_pdfs.py`.
- **Semaphores & screens (`artwork/`):** Sealed Build-7 vector masters, 40 PNG exports (`512`, `1024`, `1214`, `1298`, `2460` px in English and Spanish), notation glyph sources (`artwork/glyphs/`), proof sheets, camera scan cards, and the iPhone 17 Pro (`1206 × 2622`) screens with their vector masters: four flashcards and three lock screens (`artwork/vector-masters/`).
- **Proofs (`proofs/`):** Lean 4 formalization of the Klein four-group V₄, proofs version 2.4.2 (`TetrasemaphoreAlgebra.lean`, 118 theorems), multi-toolchain verification gate (`check.sh` across `v4.33.0`, `v4.32.2`, `v4.33.1`), statement listing (`STATEMENTS.md`), and the red-team corpus and run index (`RED_TEAM_LEAN.md`, `attack_matrix.json`, `RUN_INDEX.tsv`, `attacks/`).
- **Working record (`record/`):** Decision log (`record/decision-log.md`, 146 entries), five curated Google AI Mode exchanges (`record/exchanges.md`), release plan and failure-modes register (`record/release-plan.md`), and the test register (`record/test-register.md`).
- **Website (`site/`):** Zero-JavaScript static site deployed at `https://tetrasemaphore.systems/` (`index.html`, `note.html`, `method.html`, `404.html`, `llms.txt`, `verify.sh`, and CloudFront response-headers policies).
- **Licences (`LICENSE`, `LICENSE-CODE`, `NOTICE`):** Text and art under CC BY 4.0 (`LICENSE`); code (`.lean`, `.sh`, `.py`, `.js`, and `proofs/lean-toolchain`) under Apache License 2.0 (`LICENSE-CODE`; scope stated in `NOTICE`).
- **Manifest (`RELEASE-MANIFEST.md`):** Size and full SHA-256 for every file in the release except itself, `CHANGELOG.md` and `CITATION.cff` (283 rows), plus the "Not included, and why" register.
